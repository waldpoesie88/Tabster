# <img src="icons/icon48.png" width="32" align="center"> Tabster: Smart Tab Suspender

A lightweight, fast, and privacy-focused browser extension for Chromium-based browsers (Microsoft Edge, Google Chrome, Brave) designed to save RAM by suspending inactive tabs.

## Key Features
- **Side Panel & Popup Modes:** Seamlessly switch between a persistent browser Side Panel and a compact popup window with a single click.
- **Smart Auto-Suspension:** Automatically unloads inactive tabs after a configurable idle period (30 min, 1h, 2h, or disabled).
- **Session-Based Whitelist (Shield):** Protect specific tabs (green shield) or entire root domains including subdomains (blue shield) from suspension during your current session.
- **YouTube Timestamp Preservation:** Saves the exact playback second before suspending YouTube videos so you never lose your place.
- **Audio Tab Mixer:** Quickly find tabs playing audio and mute/unmute them individually without switching tabs.
- **Instant Live Search:** Filter active, playing, suspended, and protected tabs in real time by title or URL.
- **Bilingual UI & Font Scaling:** Instant switching between English and Russian interfaces, plus five font size presets.
- **Zero Tracking:** Works 100% locally. No analytics, no external servers, no data collection.

## Installation (Developer Mode)
1. Download or clone this repository.
2. Open `edge://extensions/` or `chrome://extensions/` in your browser.
3. Enable **Developer mode** in the corner.
4. Click **Load unpacked** and select the `Tabster` folder.
